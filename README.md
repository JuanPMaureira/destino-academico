# 🎓 Plataforma de Inteligencia Educativa - Destino Académico

## 📌 Descripción General del Proyecto
"Destino Académico" es una herramienta de Inteligencia de Negocios (BI) estructurada bajo la metodología **CRISP-DM** (Cross-Industry Standard Process for Data Mining). Su objetivo es democratizar la información sobre educación superior en Chile, entregando analítica avanzada a estudiantes, apoderados, docentes y directivos para la toma de decisiones basada en evidencia.

El sistema cruza datos públicos del SIES, integrando modelos de Machine Learning en un entorno frontend dinámico desarrollado en Python.
